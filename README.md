# MOVE PLAN — 引っ越しガントチャート

PC・iPhone・Androidのブラウザで使える、シンプルな引っ越し用ガントチャートです。サーバーやアカウントは不要です。

## できること

- 引っ越し準備のタスク一覧とガントチャートを表示
- タスクの新規追加・変更・削除、進捗率・ステータス・メモの編集
- ガントバーを横に動かして予定日を変更、両端を動かして期間を変更
- 進捗サマリーと「要確認」タスクの表示
- ブラウザへの自動保存（localStorage）
- JSON形式でのバックアップ・他端末への復元
- PC・スマホ対応、外部ライブラリ不要

## 使い方

`index.html` をブラウザで開きます。タスク名や棒をクリック（タップ）すると日付や内容を編集できます。

初期予定は **2026年12月19日搬入・12月21日退去という仮の日程** です。実際の契約締結日、入居日、旧居解約日は確定していないため、現実の条件に合わせて変更してください。旧居の解約予告は1か月前が前提ですが、**新居が確定するまでは旧居の解約連絡をしない** よう注意してください。

## GitHub Pages で公開する場合

1. GitHub でアプリ専用のリポジトリを作成し、`index.html`、`styles.css`、`app.js` をルートへアップロードします。
2. `Settings` → `Pages` → `Build and deployment` → `Deploy from a branch` を選びます。
3. `main` ブランチの `/ (root)` を選び、保存します。
4. 表示されたURLでアクセスします。公開リポジトリにした場合、**プログラムと初期サンプル予定は一般公開** されます。

編集したタスクは **その端末・ブラウザ内のみ** に保存されます。GitHubにタスクの編集内容が送信されるわけではありません。端末間で同じ予定を使う場合は「バックアップ」のJSONファイルを渡し、別端末の「JSONを読み込む」で復元してください。

## 重要な注意

- データはバックアップなしにブラウザの閲覧データを削除すると失われることがあります。
- GitHub Pagesでの公開はデータ同期やログイン機能を提供しません。
- プロジェクトの引っ越し日やタスクは初期値で、すべて利用者が変更できます。
