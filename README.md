# MOVE PLAN — 引っ越しガントチャート

PC・iPhone・Android対応。下記の同じURLを開く人同士で予定を共同編集できます。

https://july25th2015years-ux.github.io/moving-gantt-app/

- タスク、メモ、日程、進捗、並び順、引っ越し予定日を共通保存。
- 開いている画面は約3秒ごとに自動同期。再読み込みでも最新データを取得。
- 異なる項目の編集は統合。同じ項目の競合は最後に保存した変更が優先。
- 通信失敗時は未送信と表示し、端末に変更を保存して再接続時に再送。
- このURLを知っている人は全員が閲覧・編集可能。ログイン不要。
- 表示フィルターとスクロール位置は各自の画面設定。

## 既存の予定の移行

共有データが未作成なら、最初に開いた端末の予定を共有保存します。
既に共有予定がある場合、その予定を読み込みます。以前の端末内データは初回同期前のコピーを保持し、「この端末の以前の予定を共有」で確認のうえ共有側へ置き換えられます。
JSONバックアップと読み込みも利用できます。読み込み・初期化・削除は相手にも反映されます。

## 構成

- index.html / styles.css: 既存画面
- app.js: 差分保存・競合時の再取得・3秒ポーリング・端末内の未送信キュー
- 共有API: https://moving-plan-sync-yoshida.july25th2015years.chatgpt.site
- APIのソースは同Siteの管理リポジトリに保存。R2の条件付き書き込みで上書き競合を防止。

GitHub Pagesは画面配信を担当し、予定データは別の共通保存先へ保存します。端末の閲覧データ削除前には未送信がないことを確認し、必要ならバックアップしてください。
